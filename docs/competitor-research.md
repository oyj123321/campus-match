## 二、问卷设计深度拆解

### CampusDate (交大) — 65题六板块

问卷基于心理学量表（五大人格特质、价值观契合度研究），分为六大板块：

| 板块 | 内容范围 | 示例题目 |
|------|---------|---------|
| **初见** | 基本信息、择偶取向 | "你希望匹配什么性别？" |
| **心动** | 吸引力因素、外表偏好 | 形象管理、穿搭风格 |
| **远方** | 核心价值观、人生规划 | 对婚姻/孩子/事业的看法 |
| **朝夕** | 生活具体细节 | 吃辣、作息时间、整洁程度 |
| **回声** | 情感风格、相处模式 | 吵架处理方式、表达爱意方式 |
| **交心** | 深度价值观、精神契合 | 对出轨的态度、信仰重要性 |

### MatchUs (浙大) — 15维度自选

不强制填所有题。用户从 15 个维度中选最在意的 5 项并排序，系统只在这 5 维上匹配：

```
身高/学校/年龄/MBTI/家乡/运动习惯/音乐品味/
电影偏好/阅读偏好/游戏偏好/作息/饮食/旅行风格/宠物态度/消费观
```

### FDU Date — 与 CampusDate 同源

题目结构和数量类似，共享同一平台（trycampusdate.com），不同学校独立匹配池。

### 我们的差距

| | 竞品 (CampusDate) | CampusMatch (我们) |
|---|---|---|
| 题目数 | 65 | 32 |
| 板块数 | 6 | 4 |
| 缺失维度 | — | **消费观、MBTI、约会频率、未来定居城市、外貌偏好** |
| 个性化 | "标记重要"权重调整 | ✅ 已支持 |
| 一票否决 | 有 | ✅ 已支持 |

## 三、商业模式验证

### MatchUs — 唯一跑通的付费模型

```
匹配活动: ¥19.9/次 (未匹配全额退款)
月度窗口: 每月2轮
合作模式: 300+流量方 (校园墙、自媒体) 分佣
获客成本: 注册~¥200/人，认证~¥300/人
实际状态: ¥19.9 是亏本运营，靠规模+频次
未来方向: TopMatch 高端局 (全球名校/高净值)
```

### CampusDate — 完全免费

交大学生自费运维，域名+服务器约几百元/月，未商业化。

### 启示

> 校园匹配本身不赚钱。¥19.9 意味着用户愿意付钱买"有人帮我操心"。真正的商业模式在后面：**线下活动票（¥49-299/人）+ 增值服务（加速匹配/查看谁喜欢我）**。

## 五、产品启示

### 算法精度不是护城河

CampusDate 65题 vs MatchUs 15维 → 最终恋爱转化率都是 **~6%**。

```
算法能做的：把相识概率从 0 拉到接近 1
算法做不到的：让两个人产生真实吸引力
```

**核心产品价值 = 降低社交启动成本 + 制造仪式感 + 提供"被看见"的体验**

### 关键设计原则

1. **匹配理由是产品的灵魂** — 竞品用户最高频的好评词
2. **固定揭晓时间 > 随时可刷** — 制造期待感，减少频繁刷新的焦虑
3. **隐私安全感** — 不公开展示资料是竞品的共同选择
4. **"不是我在主动，是系统派的"** — 这是用户最需要的心理盾牌
5. **破冰帮助** — 匹配后沉默是最大痛点，没人解决这个问题

### 我们的差异化机会

| 竞品没做好的 | 我们可以做的 |
|------------|------------|
| 匹配后沉默 | **自动生成破冰话题**（基于共同兴趣） |
| 男女失衡 | **跨校匹配**从第1天就支持 |
| 问卷"装了" | **行为风格题**代替自评（"看到室友乱扔垃圾你第一反应是？"） |
| 无反馈闭环 | **匹配后打分** → 优化下次推荐 |
| 无澳门市场 | **唯一澳门高校恋爱匹配** |

## 六、扩展节奏参考

### MatchUs 的扩展路径

```
Phase 1: 浙大校内 (2021) — 单校验证
Phase 2: 全国 600校 (2022-2024) — 标准化问卷+互选模式
Phase 3: 全球版 + AI红娘 (2025-2026) — 新加坡/香港 + LLM匹配
```

### CampusDate 的扩展路径

```
Phase 1: 交大 (2026.3) — 7天7000人
Phase 2: 复旦+华师+同济+上财 (2026.4) — 10校
Phase 3: 清华 (2026.5) — 全国名校
```

### CampusMatch 建议路径

```
Phase 1: 澳大 → 澳科 → 澳理工 → 澳旅游 (进行中)
Phase 2: 香港5校 → 做大湾区唯一跨境内地+港澳匹配
Phase 3: 深圳/珠海/广州高校 → 大湾区内循环
```

**差异化定位：大湾区唯一的跨境校园恋爱匹配平台** — 竞品都在内地高校，港澳是空白。
