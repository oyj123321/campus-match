# 找搭子

校园广场改成组局，不再发心情帖。一场局要写清活动类型（学习、运动、吃饭、出行、看演出 / 看展、开黑）、标题、开始时间或「7 天内再议」、校内公共地点或线上、人数上限（2–12，含发起人）、费用（AA / 我请 / 免费）、性别（不限 / 只限男生 / 只限女生）。

- `/community` 默认只列出还没开始、且未取消的局，置顶优先，然后按开始时间从近到远。未注册访客看最近 3 场。筛选可以同时用：活动、学校（登录后，列出全部已开放学校）、7 天内、性别（全部 / 适合我 / 不限 / 只限男生 / 只限女生）、费用（AA / 我请 / 免费）、还有空位。适合我只留下不限、以及和自己资料里性别一致的局。
- 同校同学直接占名额。满员后加入的人进候补；有人退出或被发起人移出，最早的候补补上。发起人自己算 1 个名额，不能再加入。
- 跨校加入需要双方都在资料里勾选了对方学校。
- 确认参加前只在局的留言里说话，不交换微信，也不做站内私信。想去不占名额。放鸽子走原有举报。
- 新的局直接公开，显示昵称和学校，不能匿名。更早的表白帖不再出现在默认列表里；打开旧链接时，表白评论仍先审核，匿名旧帖仍隐藏昵称。
- 过期或取消的局不在默认列表。发起人可在详情页取消。删除后正文清空，举报和管理记录保留。
- `/admin/community`：沿用管理员登录、8 小时会话及 CSRF。审核、隐藏/恢复、置顶、举报处理、禁言 7 天/解除，操作记录原因。禁言会同步隐藏该账号已公开内容；解除禁言不会自动恢复，需管理员再审核通过。禁言账号即使删除了全部帖子也可解除。
- 所有写操作校验 CSRF；帖子 60 秒、评论 15 秒、举报 15 秒冷却，数据库原子更新实现跨进程限流。点赞/收藏使用唯一约束及显式目标状态避免重试重复计数。
- 禁言限制发帖、留言、加入和点赞，不限制查看、举报、删除自己内容或管理自己的想去。
- 删除帖子会删除评论、点赞、收藏、举报和关联审核记录。注销会删除用户自己的社区内容、其帖下评论、个人互动、禁言与相关记录。
- 目前不提供图片上传、站内私信、信誉分或人工匹配订单。界面文案跟随站点语言（简中、繁中、英文、葡文）。

## 部署

先确认代码已经推送到服务器所用分支。维护窗口暂停 `campus-match` 服务，使用与 systemd 服务相同的 Python 环境执行：

```bash
cd /opt/campus-match
git pull --ff-only
python scripts/migrate_community.py
```

迁移脚本读取现有配置，自动备份 SQLite 文件，然后创建社区表（含名额表 `community_members`）。若 `community_entries` 已存在，会补上地点、人数、费用、开始时间、再议和取消字段。重复执行安全，不修改已有用户或匹配字段。若不是 SQLite 会停止，需按实际数据库进行备份和迁移。迁移成功后启动服务，验证 `/community` 和 `/admin/community`。

应用现有 `init_db()` 也会创建新表，但 Gunicorn 仅导入应用时未必调用该函数，不应只依赖重启创建表。上线前完成上述迁移。按现有运维方式处理备份文件访问权限和保留周期。

## 验证

`python -m unittest discover -s tests -q` 运行全部测试。`python tests/browser_community.py` 用独立内存数据库和演示账号验证桌面/手机用户端及管理端，不接触真实数据。可设置 `ADMIN_BROWSER_CHANNEL=msedge` 使用已安装的 Edge。
