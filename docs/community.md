# 校园广场（第一期）

- `/community`：访客可浏览公开帖子和评论；写操作及个人帖子、收藏页面仅向验证学校邮箱的登录用户开放；无需完成匹配问卷。
- 分类：表白与心动（先审核）、认识新朋友、校园日常（直接公开）。
- 昵称或匿名纯文字发帖、评论、点赞、私有收藏、举报；用户只能删除自己的内容。
- 广场按置顶优先、时间倒序展示，20 帖一页；评论按时间顺序，30 条一页。支持分类、学校、我的帖子和收藏筛选。
- 匿名隐藏昵称，不隐藏学校；管理员可关联作者账号，不对其他用户返回作者账号编号或邮箱。
- `/admin/community`：沿用管理员登录、8 小时会话及 CSRF。审核、隐藏/恢复、置顶、举报处理、禁言 7 天/解除，操作记录原因。禁言账号即使删除了全部帖子也可解除。
- 所有写操作校验 CSRF；帖子 60 秒、评论 15 秒、举报 15 秒冷却，数据库原子更新实现跨进程限流。点赞/收藏使用唯一约束及显式目标状态避免重试重复计数。
- 禁言限制发帖、评论、点赞，不限制查看、举报、删除自己内容或管理自己的收藏。
- 删除帖子会删除评论、点赞、收藏、举报和关联审核记录。注销会删除用户自己的社区内容、其帖下评论、个人互动、禁言与相关记录。
- 目前不提供图片上传、私信、付费会员或人工匹配订单。界面第一期为简体中文，既有站点语言设置保持原行为。

## 部署

先确认代码已经推送到服务器所用分支。维护窗口暂停 `campus-match` 服务，使用与 systemd 服务相同的 Python 环境执行：

```bash
cd /opt/campus-match
git pull --ff-only
python scripts/migrate_community.py
```

迁移脚本读取现有配置，自动备份 SQLite 文件，然后只创建 6 张新增社区表和索引；重复执行安全，不修改已有用户或匹配字段。若不是 SQLite 会停止，需按实际数据库进行备份和迁移。迁移成功后启动服务，验证 `/community` 和 `/admin/community`。

应用现有 `init_db()` 也会创建新表，但 Gunicorn 仅导入应用时未必调用该函数，不应只依赖重启创建表。上线前完成上述迁移。按现有运维方式处理备份文件访问权限和保留周期。

## 验证

`python -m unittest discover -s tests -q` 运行全部测试。`python tests/browser_community.py` 用独立内存数据库和演示账号验证桌面/手机用户端及管理端，不接触真实数据。可设置 `ADMIN_BROWSER_CHANNEL=msedge` 使用已安装的 Edge。
