# 恋爱人格卡 · 视觉设计说明

> 记录 v1.9.23 十六型卡片「极简科技」风格从何而来，便于后续改版对齐气质。

---

## 一、结论（我们做成了什么）

- **一型一主题**：16 种恋爱人格各有独立渐变、强调色、线稿徽章与轻装饰
- **风格定调**：极简科技（线稿徽章 / 顶栏信息带 / 水印 / 面板角），**不做**插画小场景
- **分享同步**：页面卡与 `html2canvas` 分享图共用同一套主题；装饰只挂在内卡，避免外框叠图

相关文件：

| 文件 | 作用 |
|------|------|
| `static/personality_themes.css` | 16 型配色、顶栏、水印、网格、版式 |
| `static/personality_emblems.js` | 16 型原创几何徽章 SVG + 印章注入 |
| `static/personality_share.js` | 主题应用、分享截图（兼容 html2canvas） |
| Debug 预览 | `/dev/personality-themes` 等（仅 `FLASK_DEBUG`） |

## 二、吸收了哪些作品 / 思路

### 1. Jokeyou/mbti-test（MIT）

- 仓库：https://github.com/Jokeyou/mbti-test  
- **吸收**：16 型各配独特几何头像，而不是「全站一个图标」  
- **我们怎么用**：按恋爱人格代号（如 `EFCP` / `IFOP`）各画一枚**原创**线稿徽章（盾、罗盘、灯塔、花盆、星尘等），`currentColor` 跟随主题色；**未复制**其 SVG 资源

### 2. Tabler Icons（MIT）

- 仓库：https://github.com/tabler/tabler-icons  
- **吸收**：24×24 网格、约 2px 描边、圆角线帽的干净线稿纪律  
- **我们怎么用**：徽章笔触与留白跟这套气质对齐；图标本身为自绘，不是 Tabler 资源搬运

### 3. 常见 MBTI / 人格测试站的配色习惯

- **常见做法**：按 E/I、S/N 等**维度**换强调色  
- **我们升级**：升到「**一型一套完整卡面**」（底渐变 + 顶栏 + 徽章 + 印章），更像可收藏分享卡，而不是答题页高亮

### 4. CampusMatch 自有首页 UI（主空气感来源）

- 文件：`static/style.css`（清晨湾区 · 轻科幻）  
- **吸收**：靛 `#6366f1` / 青 `#06b6d4` / 粉 `#ec4899` / 紫与琥珀等科技色，浅色底 + 柔光，而不是深色紫黑风  
- **我们怎么用**：16 型色板从这套里拆分变奏，保证人格卡和站点是同一品牌

## 三、明确没走的路

| 方向 | 代表 | 为何不用 |
|------|------|----------|
| 大场景插画 | Flowbite Illustrations、花园/小猫整幅顶图 | 你选定极简科技后，插画仅作对比页试做（`/dev/personality-compare`），不进正式卡 |
| 植物有机风 | SBTI 一类 | 与湾区科技色产品气质不合 |
| 第三方 MBTI 商业贴图 | itch 等素材包 | 授权与风格不可控；徽章坚持自绘 |

对比结论（产品决策）：**极简科技 > 插画**。

---

## 四、结构与工程要点（美观背后的约束）

1. **顶栏信息带**：标题 / 副标题铺在 `--lp-frame` 渐变上，徽章落在顶栏右侧  
2. **装饰必须 `position: absolute`**：曾误用 `> * { position: relative }` 把徽章挤进文档流，造成「大块空顶」  
3. **分享只装饰内卡**：`lp-share-frame` 只上色，`lp-share-card` 才挂徽章 / 印章 / 水印，避免叠两层  
4. **html2canvas**：避免 `color-mix` / `mask`；失败时降级去掉装饰再截  
5. **版式**：正文左右留白、文字仍左对齐（不是 `text-align: center`）

---

## 五、改版时请保持

- 浅色科技底，不默认切深色霓虹  
- 每型仍要有可辨识徽章 + 独立色板（收藏感）  
- 分享图与页内卡一致；改 CSS 时顺带在真机点一次「分享报告」
