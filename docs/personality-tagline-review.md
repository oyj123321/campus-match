# 16人格 tagline 对抗审查报告

> 审查模式：2 Agent 对抗（共鸣审查 + 传播性审查）
> 目标：让当事人觉得"这就是我"→ 分享 → 路人觉得"有意思"→ 点击测试

---

## 审查标准

### Agent 1: 共鸣审查（当事人视角）

| 通过 | 条件 |
|------|------|
| ✅ | 能想象出真实的人说这句话 |
| ✅ | 语气匹配该人格的核心特质 |
| ⚠️ | 部分匹配但有一句出戏 |
| ❌ | 像AI写的、像标签说明书、像所有人通用 |

### Agent 2: 传播性审查（路人视角）

| 通过 | 条件 |
|------|------|
| ✅ | 刷到会停下来看 |
| ✅ | 有信息差（"我是什么？我想知道"） |
| ⚠️ | 能看但不会主动分享 |
| ❌ | 刷过去不会停留 |

---

## 逐条审查

### 1. ESCP 守护者
> 我不太会说那种话。但我说好的事，每一件都会做。你等着看。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | 守护者型的人就是这样——嘴笨、行动派。"你等着看"很真实，不服气的语气在里面 |
| 传播 | ✅ | 简洁。三句话、句号收尾，刷到会觉得这个人很稳。好奇自己是不是守护者 |

### 2. ESCA 开明领航
> 路线我查好了。你跟着就行，不用操心。想去哪儿随时说，改道来得及。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | "改道来得及"——计划派但是不固执，精准命中S+A的矛盾统一 |
| 传播 | ✅ | 有画面感。像旅行前任做的攻略，又像人生规划。两种解读都成立 |

### 3. EFCP 阳光筑巢 🔥
> 我好喜欢跟你待着啊！不是随便那种——是以后都想跟你待着那种。说真的。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | 先喊出来，再认真。先"跟你待着"再"以后都想"——EF型的心路历程一模一样 |
| 传播 | ✅ | 最后三个字"说真的"拔高了整句话，从撒娇变成承诺。会想转发 |

### 4. EFCA 浪漫牧者 🔥
> 藏不住！昨天想你了说了三次，今天还得再说一遍——我想你了。你在哪。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | 活人感最强的之一。"你在哪"三个字直接把思念变成行动指令 |
| 传播 | ✅ | 女生看到会截图发朋友圈配字"我男朋友be like:"——天然 meme 属性 |

### 5. ESOP 灯塔
> 我可以帮你把前面的路照亮。但我自己也得亮着。这个你别忘了。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | O（独立）和 E（外放）的张力全在这句话里了。会照顾人但不会消耗自己 |
| 传播 | ⚠️ | 稍微长了一点。"这个你别忘了"有点说教味，路人可能觉得"关我什么事" |

**建议调整**：删掉"这个你别忘了"，换成"你知道的"或直接句号。灯塔不需要提醒别人别忘了。

### 6. ESOA 自由先驱
> 爱你和做自己，少一个我都不舒服。你也一样——去做你的事，回来我还在。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | 双向自由宣言。不是"我给你自由"，是"你做你，我做我，爱是并行的"。自由先驱的精髓 |
| 传播 | ✅ | 后半句有安全感。不是"别走"而是"回来我还在"，克制但有力量 |

### 7. EFOP 热心管家 🔥
> 对你好是认真的。但是累了我会闷一会儿。不是生你气——充个电，回来继续对你好。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | "闷一会儿""充个电"——这代人表达情绪的真实方式。不是"我需要空间"，是"我会闷一会儿" |
| 传播 | ✅ | "热心管家"四个字 + 这段话，人设瞬间立住。有反差——热心但不是永动机 |

### 8. EFOA 春风旅人
> 我跑得是快了点。你跟上来呗——不用拽着我，并排走就行。路上的事路上说。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ⚠️ | "路上的事路上说"点题了，但"跑得是快了点"——热情有余但不太像"春风" |
| 传播 | ✅ | 并排走的意象好。但整句话偏长，"春风旅人"应该更轻盈一点 |

**建议调整**：缩短。"不用拽我。跟我一起走就行——去哪儿到了再说。"

### 9. ISCP 静谧港湾 🔥
> 你上次说的那个事。我记住了。已经弄好了。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | 三句话，九个字。一个安静的人表达爱的方式就是这样的。不说"我爱你"，说"弄好了" |
| 传播 | ✅ | 极简的力量。旁边三条短句排下来，这张卡片最好看。刷到会停下来。**最佳 I 型 tagline** |

### 10. ISCA 内秀构建
> 嗯……我其实想了很多。算了不说了。你看这个——我给你弄好了，你就知道了。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | "算了不说了"→"你看这个"——典型的自卑型表达者。做比说快 |
| 传播 | ⚠️ | "弄好了"和 ISCP (#9) 撞了。两张卡放一起就会感觉重复 |

**建议调整**：避免"弄好了"。改成"你看这个——比说的清楚。"

### 11. IFCP 温柔守望
> 我看起来什么都行。但跟你有关的那些事，我真的想了很久。不是随便的。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | F+C（随性但亲密）的精髓——表面随意，内心认真。"不是随便的"收得好 |
| 传播 | ⚠️ | 有点平淡。"什么都行"的人设不够有辨识度 |

### 12. IFCA 诗意栖居 ⚠️
> 以前觉得一个人挺好的。你来了之后。好像也没变——就是多了一个人，什么都想跟你说。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ❌ | "什么都想跟你说"太泛了。**诗意栖居**应该是"吃过苦但还愿意信"——这句没体现出来 |
| 传播 | ❌ | 路人视角：跟前几张比起来，这张像填错了人设 |

**必须重写。建议：**
> 一个人走了很久。前面很暗。你来了之后——也不是说就亮了。但走路的时候终于不用数步子了。

### 13. ISOP 沉思者 🔥
> 想清楚了。是你。这个结论我反复推过了。不会改。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | 四句话、四个句号。没有一个多余的字。"反复推过了"——思辨型的人就是会推一遍再推一遍 |
| 传播 | ✅ | 极简 + 极坚定。有判决书的感觉。路人看到会想"我好想知道我是谁" |

### 14. ISOA 孤岛哲人 🔥
> 我习惯一个人了。让你靠近……是我能给的最高规格。你知道就行。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | "最高规格"这三个字杀伤力极强。独立型人给爱不是给礼物——是给你开权限 |
| 传播 | ✅ | "你知道就行"——不需要回应，这份克制反而更动人。分享意愿强 |

### 15. IFOP 花园隐士
> 我的小世界还行。你来之后，我挪了个位置。不是客气——是真的想让你待着。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | "花园隐士"的松弛感全在里面。不是"欢迎你进入我的世界"那种宏大叙事——是"我挪了个位置" |
| 传播 | ✅ | 有反差感。一个平时不太社交的人，愿意把位置分给你。路人会觉得暖 |

### 16. IFOA 星尘游吟
> 走得慢。方向也一般。但一直在走。你要不要一起。不用说话。走就行。

| Agent | 结论 | 理由 |
|-------|------|------|
| 共鸣 | ✅ | 自嘲式的真诚。"方向也一般"——游吟诗人的味道对了。不卖惨也不硬撑 |
| 传播 | ✅ | 六句话极短。节奏像一首小诗。收尾"走就行"很轻但有余味 |

## 汇总判决

| 状态 | 数量 | 人格 |
|------|------|------|
| 🔥 高共鸣+高传播 | 8 | EFCP, EFCA, EFOP, ISCP, ISOP, ISOA, IFOP, IFOA |
| ✅ 通过 | 5 | ESCP, ESCA, ESOA, ISCA, IFCP |
| ⚠️ 需微调 | 2 | ESOP（删尾句）, EFOA（缩句） |
| ❌ 需重写 | 1 | **IFCA 诗意栖居** |

## 修复建议

### ESOP 灯塔（微调）
```
改前：我可以帮你把前面的路照亮。但我自己也得亮着。这个你别忘了。
改后：我可以帮你把前面的路照亮。但我自己也得亮着。
```
理由：删掉"这个你别忘了"。灯塔不需要开口提醒，光在那里就够了。

### EFOA 春风旅人（微调）
```
改前：我跑得是快了点。你跟上来呗——不用拽着我，并排走就行。路上的事路上说。
改后：不用拽我。跟我走——去哪儿到了再说。
```
理由：短了 60%。春风不是跑得快，是推着你往前但不推太猛。

### IFCA 诗意栖居（重写）
```
改前：以前觉得一个人挺好的。你来了之后。好像也没变——就是多了一个人，什么都想跟你说。
改后：一个人走了很久。你来了之后——也不是说就亮了。但终于不用数步子了。
```
理由：诗意栖居 = 吃过苦+还愿意信+安静的表达。"什么都想跟你说"太泛，"不用数步子了"是只属于这型人格的细节。
