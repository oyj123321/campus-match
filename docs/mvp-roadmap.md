# CampusMatch MVP 路线图

> 原则：先让真人跑通闭环，再扩学校/算法/商业化。

## 已完成

- **MVP 1.0–1.2**：认证 → 问卷 → 一对一 → 额度/批量 → 隐私修复
- **MVP 1.3**：相处说明书 + 破冰 + 本周预约揭晓
- **MVP 1.4**：跨校开关 + 相处预期 8 题 + 黑名单
- **MVP 1.5–1.6**：浅色湾区主题 + 四语言支持 + 澳门地标主视觉
- **MVP 1.7**：39题 → 126维向量修复 + 量表双维编码
- **MVP 1.8**：隐藏匹配分数 + 双向周额度 + 腾讯云部署 + 运维手册

## 当前：公测前最后准备

- [ ] 清理种子假数据，切换为真实用户注册环境
- [ ] 买域名 + 腾讯云服务器（见 `docs/deploy-tencent-lighthouse.md`）
- [ ] 澳大 5-10 人小范围测试
- [ ] 上线公测（见 `docs/beta-launch.md`）

### 架构

```
免费: 余弦相似度粗筛 + 匈牙利全局最优
VIP:  余弦 Top-20 → LLM 陪审团精排 → 个性化说明书 + 破冰话题
免费: 反馈闭环（所有人可用，数据飞轮）
```
