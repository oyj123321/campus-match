# CampusMatch MVP 路线图

> 原则：先让真人跑通闭环，再扩学校/算法/商业化。

## 已完成

- **MVP 1.0**：邮箱验证 → 32 题问卷 → 余弦匹配 → 邮件通知
- **MVP 1.0.1**：问卷 UX / 答案键 / 重匹配修复
- **MVP 1.1（进行中）**：生产开关、隐私说明、验证码限流、健康检查、择偶取向

## MVP 1.1 — 可上线

| 项 | 状态 |
|----|------|
| `FLASK_DEBUG` / Session 安全 | ✅ |
| 首页隐私与规则说明 | ✅ |
| 注册验证码限流 | ✅ |
| `/api/health` | ✅ |
| 择偶取向 looking_for（男/女/不限）+ 双向过滤 | ✅ |

成功标准：公网可访问；≥10 真人注册并填完问卷。

## MVP 1.2 — 可运营（下一刀）

- 每周匹配额度 / 冷却
- 邮件失败时页面仍完整展示结果
- 首页展示本校人数
