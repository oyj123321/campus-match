# CampusMatch MVP 路线图

> 原则：先让真人跑通闭环，再扩学校/算法/商业化。

## 已完成

- **MVP 1.0**：邮箱验证 → 32 题问卷 → 余弦匹配 → 邮件通知
- **MVP 1.0.1**：问卷 UX / 答案键 / 重匹配修复
- **MVP 1.1**：生产开关、隐私说明、验证码限流、健康检查、择偶取向
- **MVP 1.2**：每周额度/冷却、批量匹配任务、首页人数、结果页增强

## MVP 1.2 — 可运营

| 项 | 状态 |
|----|------|
| 每周新建匹配额度 + 冷却 | ✅ |
| `batch_job.py` 立即/定时批量匹配 | ✅ |
| 进程内调度 / Admin 手动触发 | ✅ |
| 邮件失败仍以页面为准展示结果 | ✅ |
| 首页各校人数 | ✅ |

### 批量匹配怎么跑

```bash
# 立刻跑一轮（测试用）
python batch_job.py --now

# 或配置 ADMIN_SECRET 后：
# curl -X POST http://127.0.0.1:5000/api/admin/batch-run -H "X-Admin-Secret: xxx"

# 生产可开进程内调度
# BATCH_SCHEDULER_ENABLED=true
```
