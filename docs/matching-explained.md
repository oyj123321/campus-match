# 匹配算法怎么理解（给开发者）

## 你点「开始匹配」时发生了什么（默认）

1. 找出同校、邮箱已验证、问卷已完成的人  
2. **择偶取向双向接受**（你想找的性别 = 对方性别，且对方也想找你的性别）  
3. 把问卷变成向量，算 **余弦相似度**（口味有多像）  
4. **一票否决**题差太大 → 跳过  
5. 按分数排序，**只取第 1 名** → 一对一  

这不是匈牙利。匈牙利用在「全校同一时刻一起分配、每人最多 1 个」的批量任务里。

## 余弦相似度（一句话）

把两个人的答案看成两串数字，看方向是否接近。越接近分越高。

## 匈牙利算法（一句话）

全校做成一张「谁和谁合拍」的表，再统一分配，避免大家都抢同一个人，并尽量让整体合拍。  
命令：`python batch_job.py --now` 或每周二定时。

## 为什么以前会看到好几个？

旧默认是 Top-5 列表推荐。已改为默认一对一。

## 为什么邮件没来？

| 情况 | 原因 |
|------|------|
| 对方是 seed 演示号 | `alice@um.edu.mo` 等不存在，SMTP 550 失败正常 |
| 以前匹配过 | 旧逻辑「更新已有」不发信，且失败也标已通知 |
| 现在 | 点匹配会再尝试发；页面会显示发给你是否成功 |

请看匹配结果上方的「邮件通知状态」。
