# 趣味性格报告（「Campus 星盘」）技术思路

> 状态：已规划，待实现  
> 来源：同学内测反馈（填完想看「自己是什么样、适合什么样的人」——娱乐向、像星座、头头是道）  
> 相关：[`multi-agent-vip-features.md`](./multi-agent-vip-features.md)（双人深度说明书 / VIP 陪审团）

---

## 要解决什么

填完 39 题后，用户除了等匹配，还想立刻得到一份**对自己有趣的解读**：

- 不需要真正「科学有用」，但要**好玩、愿填、愿分享**
- 文风类似星座专栏：分析得头头是道；偶尔「蒙对」会觉得很准
- 大家内心未必当真，但仍好奇

这和「把匹配算得更准」是两条线，不要混成一个功能。

---

## 与多 Agent VIP 的关系

| | 趣味性格报告（本文） | 多 Agent 陪审团（VIP 文档） |
|--|---------------------|---------------------------|
| 对象 | **一个人**的问卷 | **两个人**怎么相处 |
| 时机 | 交卷立刻 | 匹配成功后 / VIP |
| 成败标准 | 好玩、愿分享、「好准」感 | 少踩雷、说明书有用 |
| 成本 | 宜极低（可先零 API） | 可按次计费 |
| 是否改匹配主算法 | **否**（仍用余弦等） | 可选精排，不替代粗筛 |

**原则：** 先做单人趣味画像；匹配继续现有余弦 / 匈牙利。画像可缓存，以后再喂给双人说明书 Agent。

---

## 推荐分期（A → B → C）

### 阶段 A：规则模板「伪星座」（优先，零/低成本）

1. 按现有问卷维度粗算：价值观 / 生活习惯 / 情感风格 / 兴趣 / 相处预期  
2. 映射到 **8～12 个人工标签**（如「夜猫规划师」「温柔较真派」），每标签含：短描述、优点、小槽点、更合拍的另一半类型  
3. 从用户**真实答案**抽 2～3 条「神准句」（作息、吃辣、孩子观、影视类型等）——「蒙对」主要靠这里  
4. 交卷成功页 / 匹配中心展示：  
   **你是什么样 → 更合拍的 TA 大概什么样 → 一句可分享文案**  
5. 页脚标明：**娱乐向，不等于心理诊断 / 不保证匹配结果**

不调 LLM 也可上线，适合下一轮同学测试快速验证意愿。

### 阶段 B：单次 LLM 润色（性价比）

在 A 的结构化结果上，调 **一次** 便宜模型（如 DeepSeek）：

- 输入：标签 + 若干关键答案摘要（尽量少塞敏感原文）  
- 输出：约 800 字内趣味报告 +「适合什么样的人」+ 3 条恋爱小提示  
- 约束：星座专栏语气；娱乐声明；禁止医疗/绝对断言  

成本约几分钱/人/次，远低于 3 Agent 陪审团，但比纯模板更「头头是道」。

### 阶段 C：接到多 Agent VIP

配对后把「我的画像 + 对方画像」交给相处说明书 / 破冰 Agent（见 VIP 文档 Stage 2/3）。  
建议落库缓存，例如 `users.personality_json`（标签、摘要、生成时间、模型版本），避免每次重算。

---

## 明确不做（初期）

- 一上来上完整 3 Agent 陪审团「只为好玩」→ 贵、慢、对冷启动过重  
- 报告写成严肃心理测评或算命承诺 → 期望与合规风险  
- 用报告分数改写匹配主算法 → 与「娱乐向」冲突；匹配仍走向量相似度即可  

---

## 产品落点（示意）

```
提交问卷成功
    → 展示「Campus 星盘（娱乐向）」
    → 可进匹配中心继续预约 / 提前揭晓
    → （可选）分享卡片文案

匹配成功
    → 仍展示契合点 + 破冰（现有）
    → （阶段 C）再叠加双人说明书
```

---

## 实现时注意

- 文案四语言（zh/tw/en/pt）或先做中文娱乐版  
- 生成失败时降级到纯模板（阶段 A），不挡提交  
- 隐私：分享卡片默认不含微信号 / 学校邮箱  
- 与 [`mvp-roadmap.md`](./mvp-roadmap.md) 对齐时，建议排在「提升填完问卷即时爽感」类需求前段  

---

## 一句话

朋友要的是 **单人趣味星盘**；多 Agent 是 **双人深度说明书**。技术上：**规则标签 + 神准句（A）→ 一次 LLM 润色（B）→ 再接到 VIP 陪审团（C）**。
