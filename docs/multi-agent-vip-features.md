# 多 Agent 系统 · VIP 功能设计文档

> 状态：已规划，待实现
> 版本：v2.0 目标

---

## 架构总览

```
Stage 1: 余弦相似度 + 匈牙利算法（免费）
         全校候选人 → Top-N 召回，毫秒级，零成本
              │
Stage 2: LLM 陪审团（VIP）
         Top-N → 3 Agent 深度评估 → 精选 1 人 + 个性化相处说明书
              │
Stage 3: 破冰话题 Agent（VIP）
         生成 3-5 条基于两人具体答案的自然对话开场
              │
Stage 4: 反馈闭环（免费，所有人可用）
         匹配 7 天后推送 → "和 XXX 聊得怎么样？"
         → 反馈数据优化下次匹配权重
```

## 核心原则

**余弦做粗筛，Agent 做精排。两者不冲突。**

余弦相似度负责"在 500 人中快速筛掉明显不合适的"（免费、毫秒级、全量对比）。LLM Agent 负责"在 Top 20 中精准区分'不同但互补'和'不同且冲突'"（VIP、按次计费、深度推理）。两个阶段解决的问题不同，不能相互替代。

## VIP 功能详解

### 1. 匹配质量陪审团（Match Quality Jury）

**解决的问题：** 余弦相似度 60% 的匹配不一定合适。算法只看向量距离，不知道什么是"互补"什么是"冲突"。

**模式：** 三 Agent 独立评估 + 共识

```
用户 A + 用户 B 的完整问卷答案
    │
    ├── Agent 1: 生活方式兼容性法官
    │   视角："这两个人的日常节奏能合拍吗？"
    │   审阅：作息、整洁、饮食、运动、宠物、旅行风格
    │
    ├── Agent 2: 价值观对齐度法官
    │   视角："他们对人生重要问题的看法是否相容？"
    │   审阅：婚姻、孩子、出轨、消费、信仰、事业vs家庭
    │
    └── Agent 3: 情感风格契合度法官
        视角："他们表达爱和解决冲突的方式能互相接住吗？"
        审阅：冲突处理、独处需求、浪漫vs务实、沟通频率、前任态度
    │
    ▼
共识分 + 分歧标注 → 个性化"相处说明书"（不是模板，是真正基于两人答案的人话）
```

**输出示例：**

> **你们的匹配分析**
>
> 💚 **合拍的地方**
> - 你们对婚姻和孩子有几乎一模一样的期待——这在匹配池里只占 12%
> - 吵架风格互补：她需要先冷静五分钟，而你习惯立刻沟通。知道这一点比什么都重要
> - 对宠物态度一致（都想养）
>
> ⚡ **需要磨合的地方**
> - 她凌晨两点还在写歌，你早上六点跑步。作息相反不一定是坏事——但你们需要协商"共同时间"放在几点
> - 你们对出轨的态度差异较大（她:绝对不可原谅 / 你:可以尝试修复）。建议第一次见面就坦诚聊开
>
> 💬 **破冰话题**（自动生成，见下节）

**API 成本：** DeepSeek-V3 约 ¥0.006/次（3 Agent × ~2000 tokens入 + ~300 tokens出）

### 2. 动态破冰话题（Dynamic Icebreaker）

**解决的问题：** 竞品最大痛点——匹配成功后加了微信就沉默。转化率仅 6%。

**实现：** 基于陪审团输出 + 两人原始答案，单 Agent 生成 3-5 条自然到不像 AI 写的开场。

**输出示例：**

> 1. "你们都觉得《沙丘》是近年最好的科幻片——但你对第三部的剧情预测是什么？我跟一个人打了赌。"
> 2. "我注意到你每天早上六点跑步，而我凌晨两点还在写歌。如果我们一起旅行，你猜谁会被迫早起？"
> 3. "问卷里你说吵架时会先冷静再沟通——我想提前说，如果以后我们闹矛盾了，我希望你至少发一句'我去冷静，不是不理你'。"

**API 成本：** DeepSeek-V3 约 ¥0.003/次

### 3. 问卷真实性检测（Authenticity Check）

**解决的问题：** 竞品第二大痛点——用户填的是"理想中的自己"，不是真实的自己。见面后落差巨大。

**模式：** 对抗 Agent（日报系统同款 Adversarial Agent 思路）

```
用户完整问卷 → Adversarial Agent:
    "这个人的回答是否存在自我美化、内部矛盾、或社交期望偏差？"
    ├── 声称"每天运动"但选"周末宅家达人" → 行为矛盾
    ├── 所有核心价值观都选中间值(3) → 社交期望偏差
    ├── 核心价值观全是极端选项 → 可能是真实表达，也值得提醒
    └── 择偶取向 + 所有答案指向"其实更适合单身" → 自我认知偏差
    │
    ▼
可信度评分 + "以下 3 个回答可能与真实情况有偏差"提示
```

**注意：** 此检测仅作为匹配参考，不对用户公开。用于内部权重调整——低可信度答案在匹配时自动降权。

**API 成本：** DeepSeek-V3 约 ¥0.005/次

### 4. 自然语言理想型输入（NL Ideal-Type）

**解决的问题：** 39 题问卷对部分用户劝退。有人说"我就想找个能一起看电影的人"，填 39 题就跑了。

**模式：** 提取 Agent 转自然语言 → 问卷参数。

```
用户输入: "想找个安静一点的，可以一起看书、周末去路环徒步的"

    ▼
Profile Extractor Agent:
    → 安静 → 独处需求高 (Q19: 4-5)
    → 看书 → 阅读偏好: 文学/小说 (Q27)
    → 路环徒步 → 户外 (Q29: 1-2), 徒步/登山 (Q30)
    │
    ▼
预填问卷 + "以下是我们根据你的描述自动填写的答案，请检查并调整后提交"
```

**降门槛利器。** MatchUs 已在做类似方向（"AI 红娘"）。

**API 成本：** DeepSeek-V3 约 ¥0.01/次

## 免费功能：匹配反馈闭环

### 5. Feedback Loop（所有人免费）

**解决的问题：** 所有竞品匹配完就完了，没有反馈。没人知道用户是否真的聊上了。

**为什么免费：** 反馈数据是系统的命脉。越多反馈 → 权重越准 → 匹配越好 → 用户越多 → 更多人愿意付费开 VIP。免费是为了让飞轮转起来。

**流程：**

```
匹配 7 天后
    │
    ▼
系统邮件/页面: "你和 XXX 聊得怎么样？"
    ├── 😊 聊得很好 → 提取成功信号 → 这批维度权重++
    ├── 😐 一般般 → 不做调整
    ├── 😞 完全聊不来 → 提取失败信号 → 标注差异维度
    └── 未回复（3天后默认按钮或自动忽略）
    │
    ▼
下次匹配: 权重自适应
    "对话流畅度"维度权↑，"电影品味"维度权↓（此用户偏好由实际行为决定，而非问卷申报偏好）
```

**这是真正的护城河。** 竞品全都没做这个。数据飞轮启动后谁也追不上——因为用户反馈是全新的训练信号，不是从静态问卷能推导出来的。

## 商业模式设计

| 功能 | 免费 | VIP | 理由 |
|------|------|-----|------|
| 基础匹配（余弦 + 匈牙利） | ✅ | — | 核心价值，免费让人进来 |
| 匹配结果通知 | ✅ | — | 邮件免费 |
| LLM 陪审团（个性化相处说明书） | — | ✅ | API成本 + 用户感知最强 |
| 动态破冰话题 | — | ✅ | 直接打竞品痛点 |
| 问卷真实性检测 | — | ✅ | 后台运行，不直接对用户 |
| 自然语言理想型输入 | — | ✅ | 降门槛，拉升注册转化率 |
| 反馈闭环 | ✅ | — | **数据命脉，必须免费** |

```
VIP 月度: ¥9.9/月（无限次陪审团匹配 + 破冰 + 理想型）
```

## 与现有系统的关系

```
现有系统（v1.x）:
  问卷答案 → 126维特征向量 → 余弦相似度 → 模板化 insight
  优点: 快速、免费、全量
  缺点: insight 是模板，不能理解"互补"

VIP Agent 系统（v2.0）:
  余弦 Top-20 → LLM 陪审团 → 个性化说明书 + 破冰话题
  优点: 人话解释、互补识别、破冰自然
  缺点: API调用成本、延迟（~1秒/次）

架构: 混合模式
  - 免费用户: 纯余弦（现有系统）
  - VIP 用户: 余弦粗筛 → Agent 精排 → 个性化结果
  - 所有人: 反馈闭环（免费）
```

## 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| LLM API | DeepSeek-V3 | 性价比最高（¥1/百万token入），中文质量好 |
| Agent 框架 | 自研（参考日报系统 Adversarial Agent） | 不需要 LangChain，3 个 Agent 逻辑很简单 |
| 调用模式 | 串行（先召回后精排） | 避免全量对比的 API 成本爆炸 |
| 降级策略 | API失败 → fallback到余弦结果 | 不因 API 故障而阻断匹配 |
