# 匹配得分细算推演（本机真实样例）

用本机库里一对有效配对，把 **`score = 0.5849`** 从编码推到公式结果。  
样例用户（仅本地/内测数据，勿当生产隐私）：**内测10（A）** × **Jack（B）**；双方均未标记「很重要」题，权重全程为 1。

相关概览见 [matching-explained.md](./matching-explained.md)；实现见 `questionnaire.build_feature_vector` / `cosine_similarity`。

---

## 总公式

\[
\text{score}=\frac{\vec{A}\cdot\vec{B}}{\|\vec{A}\|\,\|\vec{B}\|}
=\frac{\sum_{i=1}^{126} A_i B_i}{\sqrt{\sum A_i^2}\,\sqrt{\sum B_i^2}}
\]

本对结果：

| 符号 | 数值 |
|------|------|
| 点积 \(\sum A_i B_i\) | **20.25** |
| \(\|\vec{A}\|\) | **≈ 5.85235** |
| \(\|\vec{B}\|\) | **≈ 5.91608** |
| 相除 | \(20.25 / (5.85235 \times 5.91608)\) ≈ **0.58487 → 入库 0.5849** |

门槛默认约 **0.15**（`MATCH_MIN_SCORE`）；过门槛后再查一票否决（原始答案，不走向量）。

---

## 1. 126 维怎么来

不是「39 题 = 39 个数」。

| 题型 | 题数 | 编码 | 维数 |
|------|------|------|------|
| 量表 1–5 | 30 | 每题拆成 left + right | 30 × 2 = **60** |
| 多选 | 9 | 每个选项 0/1 | 选项合计 **66** |
| 留言文字 | 1 | 不进向量 | 0 |
| **合计** | | | **126** |

### 量表编码

\[
\text{right}=\frac{\text{选值}-1}{4},\quad
\text{left}=1-\text{right}
\]

写入 `[left, right]`。若标「很重要」则再 ×2。

| 选值 | 写入 |
|------|------|
| 1 | `[1.00, 0.00]` |
| 2 | `[0.75, 0.25]` |
| 3 | `[0.50, 0.50]` |
| 4 | `[0.25, 0.75]` |
| 5 | `[0.00, 1.00]` |

该题对点积贡献：

\[
\text{dot}_{\text{题}}=A_{\text{left}}B_{\text{left}}+A_{\text{right}}B_{\text{right}}
\]

### 多选编码

选中=1，未选=0。权重为 1 时，一题贡献 ≈ **共同选项个数**。

### Q1（两人都选 2）

\[
A=[0.75,0.25],\ B=[0.75,0.25]
\]
\[
0.75\times0.75+0.25\times0.25=0.625
\]

### Q8（两人都选 1）

\[
A=[1,0],\ B=[1,0]\ \Rightarrow\ \text{dot}=1.0
\]

### Q2（A=3，B=4）

\[
A=[0.5,0.5],\ B=[0.25,0.75]
\]
\[
0.5\times0.25+0.5\times0.75=0.5
\]

### Q18 表达爱意（多选）

交集仅「拥抱牵手等接触」→ **dot = 1.0**。

### Q26 音乐（多选）

## 4. 向量长度与最终得分

\[
\|\vec{A}\|=\sqrt{\sum_{i=1}^{126} A_i^2}\approx 5.85235
\]
\[
\|\vec{B}\|=\sqrt{\sum_{i=1}^{126} B_i^2}\approx 5.91608
\]
\[
\text{score}=\frac{20.25}{5.85235\times 5.91608}\approx\mathbf{0.5849}
\]

除以长度比的是 **方向**像不像，不是「39 题对上了百分之几」。勾选多但彼此无交集的多选题会拉长范数、略压低余弦。

---

## 5. 能量流（一句话）

```
答案 → 126 维 → 逐维乘加得点数 20.25
     → 各自算长度 ≈5.85 / 5.92
     → 20.25 ÷ (5.85×5.92) = 0.5849
     → 与门槛、一票否决、一对一规则一起决定是否落库为配对
```

复现（需本机有这对用户数据）：

```bash
python -c "from questionnaire import build_feature_vector, cosine_similarity; ..."
```

或直接读 `matches.score` / 用双方 `feature_vector_json` 重算余弦。
