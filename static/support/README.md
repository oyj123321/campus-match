# 赞助二维码放这里

`/support` 页面会自动扫描本目录，**放了哪个就显示哪个，没放的不显示**（都没放则显示占位说明）。

| 文件名 | 页面上的标题 |
|--------|--------------|
| `wechat.png` | 微信赞赏（推荐用微信「赞赏码」；个人收款码易过期） |
| `mpay.png` | MPay 澳门钱包（可选） |

当前站上只挂微信赞赏。支付宝个人码易过期，已不使用。

- 扩展名支持 `png` / `jpg` / `jpeg` / `webp`，按此顺序取第一个存在的。
- 建议宽度 500–800px 的方图；页面显示宽度 200px。
- **微信**：在 App 里点「保存赞赏码」再上传，比截图更清晰、扫码更稳。
- 出图前把收款码周围的多余留白裁掉，扫码更快。

改文件名或新增渠道：改 `app.py` 里的 `SUPPORT_QR_CANDIDATES`，并在 `static/i18n.js` 补对应的 `sup.*` 标题。

**注意**：本仓库是公开的，放进来的收款码会随代码公开（反正也会展示在网站上）。若不想进仓库，可以只上传到服务器，并在 `.gitignore` 加 `static/support/*.png`。
